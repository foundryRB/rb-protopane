# RB Software Engineering

Use the RB Software Engineering identity: the brand green, system font stacks, a near-black technical stage, dual-scale grids, drifting light, rising particles and a three-circle orbit.

## Identity

The RB tile accompanies "Software Engineering", with "RB" below in a tracked mono line. Dark uses the light tile on the stage; Light uses the ink tile on paper. Never redraw or replace this lockup with an invented symbol. The assets folder holds the approved tile.

## Modes and materials

Dark and Light use identity.json. Glass and Solid are independent of mode. Selected controls must have an inverse filled background and a checkmark in both modes. Dense reading surfaces are opaque.

## Motion and type

Keep ambient motion in backgrounds and connective elements. Text stays still. Freeze on reduced motion and print, and pause hidden documents. Text uses the system font stacks declared in identity.json; JetBrains Mono carries the mono line.

## Exchange

Each slide theme owns its classes, layout and chrome. Review page composition when selecting a different theme.
