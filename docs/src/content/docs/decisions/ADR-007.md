**Date**: 2026-10-03
**Status**: Decided. Supersedes the typography clause of [ADR-003](../adr-003/); the rest of ADR-003 stands.

## Context

The `--font-sans` token is the typeface of every screen, and it leaves in the exported theme like any other token. In a design session the customer picks the brand's type from the theme panel's typography presets and judges the prototype by how it reads: a brand set in a rounded or display family looks wrong in a system stack, however exact the colours are. [ADR-003](../adr-003/) self-hosts everything the canvas needs to render markup themed (the Tailwind runtime, the token config, the token stylesheet), so a session works offline and behind strict egress. Brand typography is the part of the look that self-hosting does not cover for free: a family needs font files, and each family carries a licence.

## Decision

The typography presets (`FONT_PRESETS` in `frontend/src/lib/theme.ts`) offer two kinds of `--font-sans` value:

- **Three system stacks** (Modern, Editorial, Technical), each ending in a generic family. They render with no network.
- **Six curated webfont families** (Baloo 2, Fredoka, Nunito, Playfair Display, Poppins, Space Grotesk). Each stack leads with its family and falls back to a system stack.

One Google-hosted font sheet carries the six families at two weights each: 400, plus 700, or 600 for Fredoka and Poppins. The canvas iframe loads it beside the token stylesheet (`FONT_CSS` in `frontend/src/Editor.tsx`), so a screen renders in the picked family, and the chrome loads the same sheet (`frontend/index.html`), so the typography picker previews each preset in its own family. That sheet is the one online dependency the canvas takes.

A saved `--font-sans` value is a font-family stack and nothing else: the theme gate admits only family names, quotes, commas, and hyphens in that token, so it never carries a font file or a font URL into the exported theme. The real frontend build self-hosts the families the stack names (for example through Fontsource).

## Rationale

- Typography fidelity is what the session is for: the customer approves a look, and the type is a large part of it. A system stack standing in for a brand family puts a look in front of the customer that the built product will not have.
- The dependency degrades instead of breaking. Every webfont stack falls back to a system family, so offline or behind a blocked CDN the canvas still renders fully themed in a system face, and the system-stack presets render exactly as they do online. The asset whose absence would leave the canvas unstyled, the Tailwind runtime, stays self-hosted (ADR-003).
- The list is curated, so the licence question is answered once: all six families are published under the SIL Open Font License, free to use in the session and to self-host in the handed-off frontend.
- The handoff stays portable. The token is a font-family stack and nothing more, so the real frontend takes no dependency on the CDN the session used.

## Alternatives considered and rejected

- **System stacks only** (the typography clause of ADR-003): a canvas with no online dependency at all, but it cannot show a brand's own type, so the customer approves typography the product will not ship with.
- **Self-hosting the six families in the image**: fidelity and a fully offline canvas together, at the cost of carrying the font files for twelve weights, and their licence texts, in the repository and the image. The CDN sheet is the chosen trade: it keeps font binaries out of both, at the price of a dependency whose failure only drops the brand face to its system fallback.
- **Loading whatever family the theme names**: unlimited variety, but every theme becomes an unvetted licence and an arbitrary font host the canvas fetches from. The curated sheet keeps the dependency to one known host and open licences.
